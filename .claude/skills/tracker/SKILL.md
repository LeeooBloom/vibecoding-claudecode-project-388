# Трекер цен

Обходит список ссылок, для каждой получает `{ regular_price, sale_price, has_credit }` по правилам скилла `extract-price` и сводит результаты в одну таблицу.

## Вход

Список URL, по одному на страницу товара. Источник списка:

1. Ссылки из сообщения пользователя, если они есть.
2. Иначе — файл `.claude/skills/tracker/urls.txt`: одна ссылка на строку, строки с `#` и пустые игнорируются.

Если список пуст, попроси пользователя прислать ссылки и не продолжай.

## Шаги

1. **Подготовь список.** Убери дубликаты и рекламные метки (`utm_*`, `yclid`, `etext` и всё после `?`). Если ссылки пришли в сообщении, запиши их во временный файл, по одной на строку.

2. **Собери цены** одной командой:

   ```bash
   .claude/skills/tracker/scripts/collect.sh                 # список из urls.txt
   .claude/skills/tracker/scripts/collect.sh /путь/к/списку  # свой список
   ```

   Для каждой ссылки скрипт загружает HTML, разбирает его парсером `extract-price/scripts/parse_price.py` и печатает строку JSON:
   `{"url", "regular_price", "sale_price", "has_credit", "error"}`.
   Ссылки обходятся по очереди. Если страница не ответила `200`, скрипт делает одну повторную попытку с сохранёнными cookie.

   Если скрипт недоступен, пройди ссылки сам, применяя к каждой скилл `extract-price`.

3. **Проверь каждую строку** по правилам `extract-price`. Например, главная `ozon.ru/travel/` — это не страница товара: число из такой страницы считай ненайденной ценой.

4. **Собери таблицу** и выведи её пользователю.

## Формат ответа

Таблица в Markdown, одна строка на URL, в порядке списка. В колонке «Сайт» — домен без `www.`:

| Сайт | Обычная цена | Цена со скидкой | Рассрочка | Статус |
|---|---|---|---|---|
| onetwotrip.com | 3 694 ₽ | — | нет | ✅ |
| ozon.ru | 3 210 ₽ | — | есть | ✅ |
| example.com | — | — | — | ⚠️ страница не загрузилась (HTTP 404) |

- Цены — с разделителем тысяч и `₽`. `null` → `—`.
- Под таблицей одной строкой: сколько ссылок обработано, у скольких цена найдена и где самая низкая цена (с учётом `sale_price`, если она есть).
- **Каждую ссылку, по которой цена не найдена, явно перечисли** со ссылкой и причиной из `error`: «⚠️ Цена не найдена: `<URL>` — <причина>».

После таблицы приложи те же данные в JSON — массив объектов `{ url, regular_price, sale_price, has_credit }`. Его будут использовать следующие шаги трекера.

## Пока не делай

Эти этапы появятся позже. До тех пор не выполняй их и не имитируй:

- **Хранение:** сохранять результаты запуска (например, в репозиторий `tracker-data`).
- **Diff:** сравнивать с прошлым запуском и выделять значимые изменения цены.
- **Telegram:** отправлять уведомления об изменениях.

Скилл сейчас только собирает и показывает таблицу.
