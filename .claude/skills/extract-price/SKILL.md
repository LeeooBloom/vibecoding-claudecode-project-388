# Извлечение цены товара

## Вход

Один URL страницы товара. Если ссылки нет или их несколько, попроси одну ссылку и не продолжай.

## Выход

Ровно один JSON-объект:

```json
{ "regular_price": 3694, "sale_price": null, "has_credit": false }
```

| Поле | Тип | Значение |
|---|---|---|
| `regular_price` | число или `null` | Обычная цена без скидки. |
| `sale_price` | число или `null` | Цена со скидкой; `null`, если скидки нет. |
| `has_credit` | `true` / `false` | Предлагается ли на странице рассрочка или кредит. |

## 1. Получи содержимое страницы

Загружай **сырой HTML** через Bash, а не WebFetch: WebFetch превращает страницу в markdown и теряет JSON-LD и атрибуты `content`, в которых лежит точная цена.

```bash
mkdir -p "${TMPDIR:-/tmp}/extract-price" && curl -sSL --max-time 30 \
  -A 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/130.0 Safari/537.36' \
  -H 'Accept-Language: ru' -o "${TMPDIR:-/tmp}/extract-price/page.html" -w '%{http_code}\n' "<URL>"
```

- Код не `200` или файл пустой → цена не найдена (раздел 5).
- Если сеть облачной сессии не пускает на сайт (`CONNECT tunnel failed, response 403`, `ENOTFOUND`), хост нужно добавить в разрешённые в настройках окружения.

## 2. Разбери HTML

Запусти парсер из папки скилла, он использует только стандартную библиотеку Python:

```bash
python3 -I .claude/skills/extract-price/scripts/parse_price.py "${TMPDIR:-/tmp}/extract-price/page.html"
```

Он печатает `{ regular_price, sale_price, has_credit, source, error }`. Поля `source` и `error` служебные: в ответ их не включай, `error` используй в разделе 5.

Если скрипт недоступен, ищи цену вручную в том же порядке, остановившись на первом найденном источнике:

1. **JSON-LD** `<script type="application/ld+json">` → объект `@type: Product` (может лежать внутри `@graph`) → `offers.lowPrice` (у `AggregateOffer`) или `offers.price`, валюта в `offers.priceCurrency`.
2. **Мета-теги** `product:price:amount` / `og:price:amount`.
3. **Микроразметка**: атрибут `content` у элемента с `itemprop="lowPrice"` или `itemprop="price"`.
4. **Видимый текст**: числа рядом с `₽`, `руб.`, `р.`. Бери минимальную цену товара. Платежи в месяц и цены из блоков «Похожие» и «С этим покупают» не считаются.

## 3. Где цена на известных сайтах

Проверено 12.11.2026 на маршруте Москва → Минеральные Воды.

| Сайт | Пример URL | Где цена | Результат |
|---|---|---|---|
| OneTwoTrip | `onetwotrip.com/ru/aviabilety/MOW_MRV/` | JSON-LD `Product → offers (AggregateOffer).lowPrice`, `priceCurrency: RUB`. В тексте — «от 3694 ₽» и календарь цен по дням. | `3694` |
| Kupibilet | `kupibilet.ru/aviabilety/iz-moskva/v-mineralnye-vody` | JSON-LD в `@graph`: `Product → offers (AggregateOffer).lowPrice` (есть и `highPrice`), у каждого `Flight` свой `Offer.price`. **`line-through` здесь зачёркивает старое время вылета, а не цену**: это не скидка. | `3194` |
| БилетыПлюс | `biletyplus.ru/aviabilety/moskva-mow/mineralnye-vody-mrv` | JSON-LD нет. Микроразметка `itemprop="lowPrice" content="2194"`, валюта `itemprop="priceCurrency" content="RUB"` (в тексте «р.»). Календарь цен — в JS-переменной `calendarData` (`minPrice` по датам). | `2194` |
| Ozon Travel | `ozon.ru/travel/flight/moskva-mow/mineralnye-vody-mrv/` | JSON-LD `Product → offers (AggregateOffer).lowPrice` (строкой, `"3210"`). В тексте — «от 3 210 ₽» по рейсам и календарь «от N ₽» по дням. В способах оплаты есть «Ozon Рассрочка» → `has_credit: true`. | `3210` |

На страницах направлений агрегаторы показывают **минимальную цену «от»**, а не одну цену билета. Её и бери как `regular_price`. Зачёркнутой цены там нет, поэтому `sale_price` = `null`. Рассрочка нашлась только у Ozon; на остальных сайтах `has_credit` = `false`.

**Ozon Travel: нужна страница направления, а не главная.** Главная `ozon.ru/travel/` — витрина отелей и промо-акций. JSON-LD с ценой там нет, а «цена» из текста (например, `600 ₽`) к авиабилетам не относится. Если пользователь дал главную, найди на ней ссылку вида `/travel/flight/<откуда>-<код>/<куда>-<код>/` или попроси ссылку на направление. Путь `/travel/flights/...` (с `s`) отдаёт 404.

**Перед загрузкой убери из URL рекламные метки** (`utm_*`, `yclid`, `etext`, `ybaip`, `__rr` и т. п.): на цену они не влияют.

## 4. Нормализуй число и валюту

- Убери обычные, неразрывные (` `, `&nbsp;`) и узкие (` `, ` `) пробелы: `"3 694"` → `3694`.
- Убери символы и слова валюты и префиксы: `₽`, `руб.`, `р.`, `RUB`, `от`.
- Десятичную запятую замени точкой: `"3 694,50 р."` → `3694.5`. Целое значение оставляй целым: `3194`, а не `3194.0`.
- Значения из JSON-LD и `content` бывают строками (`"3194"`): тоже приводи их к числу.
- Валюта — код ISO 4217: `₽` / `руб.` / `р.` → `RUB`, `$` → `USD`, `€` → `EUR`. Если валюта не `RUB`, упомяни это пользователю, чтобы трекер не сравнил рубли с долларами.
- Скидка: есть зачёркнутая цена (`<s>`, `<del>`, класс `old-price` / `line-through`) **с символом валюты** и она больше текущей → `regular_price` = зачёркнутая, `sale_price` = текущая.
- `has_credit` = `true`, если на странице есть «рассрочка», «в кредит», «оплата частями», «Долями», «Сплит», «Плайт», «₽/мес».

## 5. Если цена не найдена — сообщи пользователю

Не придумывай и не угадывай цену. Обязательно явно сообщи пользователю одной строкой с причиной:

> ⚠️ Цена не найдена: `<URL>` — <причина: страница вернула код N / цены подгружаются JavaScript-ом / защита от ботов (капча) / цена на странице не найдена / сайт недоступен из сети сессии>.

Затем верни:

```json
{ "regular_price": null, "sale_price": null, "has_credit": false }
```

Для сайтов, где цена грузится только JavaScript-ом (страницы поиска с капчей), предложи пользователю ссылку на статическую страницу направления того же сайта или другого агрегатора из таблицы выше.

## Правила

- Одна ссылка — один объект.
- Скилл только извлекает цену: не сохраняй результат и никуда его не отправляй.
