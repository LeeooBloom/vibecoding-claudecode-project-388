# Извлечение цены товара

Скилл получает ссылку на страницу товара и возвращает цену в одном и том же формате, чтобы трекер мог сравнить её с прошлыми значениями.

## Вход

- `url` — ссылка на страницу товара (обязательно).

Если ссылки нет, попроси её у пользователя и не продолжай.

## Шаги

1. **Загрузи страницу** через WebFetch по `url`. Попроси вернуть разметку с ценой: блоки `<script type="application/ld+json">`, мета-теги `og:` / `product:` и видимый текст рядом с ценой и кнопкой «В корзину».

2. **Найди цену**, проверяя источники в таком порядке и останавливаясь на первом надёжном:
   1. JSON-LD со `@type: Product` → `offers.price` / `offers.lowPrice`, `offers.priceCurrency`, `offers.availability`.
   2. Мета-теги `product:price:amount` и `product:price:currency` (или `og:price:*`).
   3. Микроразметка `itemprop="price"` и `itemprop="priceCurrency"`.
   4. Видимый текст: цена рядом с названием товара и кнопкой покупки.

3. **Выбери правильную цену**, если их несколько:
   - бери текущую цену продажи, а не зачёркнутую старую;
   - старую цену, если она есть, запиши в `old_price`;
   - не бери цены по подписке, рассрочке («от 990 ₽/мес») и цены других товаров из блоков «Похожие» и «С этим покупают».

4. **Нормализуй значения:**
   - `price` — число без пробелов и символов валюты: `"12 990,50 ₽"` → `12990.5`;
   - `currency` — код ISO 4217: `₽`/`руб.` → `RUB`, `$` → `USD`, `€` → `EUR`;
   - `availability` — одно из `in_stock`, `out_of_stock`, `unknown`.

5. **Верни результат** строго в формате ниже, без лишнего текста.

## Формат ответа

```json
{
  "url": "https://example.com/product/123",
  "title": "Название товара",
  "price": 12990.5,
  "old_price": 15990,
  "currency": "RUB",
  "availability": "in_stock",
  "source": "json-ld",
  "checked_at": "2026-11-12T10:00:00Z"
}
```

- `old_price` — `null`, если скидки нет.
- `source` — где нашлась цена: `json-ld`, `meta`, `microdata` или `text`.
- `checked_at` — текущее время в UTC (ISO 8601).

## Если цену найти не удалось

Не придумывай и не угадывай цену. Верни:

```json
{
  "url": "https://example.com/product/123",
  "price": null,
  "error": "Краткая причина: страница не загрузилась / требуется вход / цена не найдена / капча",
  "checked_at": "2026-11-12T10:00:00Z"
}
```

## Правила

- Одна ссылка — один результат. Для нескольких ссылок повтори шаги для каждой и верни массив.
- Не сохраняй и не отправляй результат сам: это задача других скиллов трекера.
- Если цена отличается в разных источниках на странице, бери JSON-LD и упомяни расхождение в поле `note`.
