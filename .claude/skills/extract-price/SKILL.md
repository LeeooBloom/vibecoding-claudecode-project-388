# Извлечение цены товара

## Вход

Один URL страницы товара. Если ссылки нет или их несколько, попроси одну ссылку и не продолжай.

## Выход

Ровно один JSON-объект, без лишнего текста:

```json
{ "regular_price": 15990, "sale_price": 12990, "has_credit": true }
```

| Поле | Тип | Значение |
|---|---|---|
| `regular_price` | число | Обычная цена товара без скидки. |
| `sale_price` | число или `null` | Цена со скидкой; `null`, если скидки нет. |
| `has_credit` | `true` / `false` | Предлагается ли на странице рассрочка или кредит для этого товара. |

## Шаги

1. **Загрузи страницу** через WebFetch по URL. Попроси вернуть блоки `<script type="application/ld+json">`, мета-теги `product:price:*` / `og:price:*`, элементы с `itemprop="price"` и видимый текст вокруг цены и кнопки «В корзину» / «Купить».

2. **Найди цены** в таком порядке, остановившись на первом надёжном источнике:
   1. JSON-LD со `@type: Product` → `offers.price`, `offers.highPrice` / `offers.lowPrice`, `priceSpecification`.
   2. Мета-теги `product:price:amount`.
   3. Микроразметка `itemprop="price"`.
   4. Видимый текст рядом с названием товара и кнопкой покупки.

3. **Разбери цены:**
   - На странице две цены: зачёркнутая (старая) и актуальная, причём актуальная меньше. Тогда зачёркнутая — это `regular_price`, актуальная — `sale_price`.
   - Цена одна. Тогда это `regular_price`, а `sale_price` = `null`.
   - Не принимай за цену товара платёж в месяц («от 990 ₽/мес»), цену по подписке или карте лояльности, если есть обычная цена, и цены из блоков «Похожие товары» и «С этим покупают».

4. **Определи `has_credit`.** Ставь `true`, если на странице этого товара есть предложение рассрочки или кредита: «рассрочка», «в кредит», «оплата частями», «Долями», «Сплит», «Плайт», «от N ₽/мес» и т. п. Иначе `false`.

5. **Нормализуй числа:** без пробелов, символов валюты и разделителей тысяч, дробная часть через точку. Например, `"12 990,50 ₽"` → `12990.5`.

6. **Верни объект** в формате из раздела «Выход».

## Если цену найти не удалось

Не придумывай и не угадывай цену. Сначала одной строкой назови причину: страница не загрузилась, нужен вход, капча или цена не найдена. Затем верни:

```json
{ "regular_price": null, "sale_price": null, "has_credit": false }
```

## Правила

- Одна ссылка — один объект.
- Скилл только извлекает цену: не сохраняй результат и никуда его не отправляй.
