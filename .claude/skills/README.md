# Скиллы проекта

Здесь живут скиллы Claude Code для трекера цен. Каждый скилл — отдельная папка с файлом `SKILL.md`:

```
.claude/skills/
└── <имя-скилла>/
    ├── SKILL.md        # обязательный: frontmatter + инструкции
    └── ...             # необязательно: скрипты, шаблоны, примеры
```

Минимальный `SKILL.md`:

```markdown
---
name: имя-скилла
description: Что делает скилл и когда его вызывать.
---

# Имя скилла

Пошаговые инструкции для Claude.
```

Claude Code подхватывает скиллы из этой папки автоматически; вызвать вручную можно командой `/<имя-скилла>`.
